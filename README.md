# flutter_riverpod_clean-architecture_dio_rest-api

🚀 A simple yet scalable Flutter app that displays a list of countries using the **CLEAN architecture**.  
It uses **Riverpod** for state management, **Dio** for REST API calls, and follows a modular, testable code structure suitable for real-world apps.

---

## 🌍 Flutter Countries App

This project demonstrates how to build a Flutter application using:

- **Riverpod** for reactive state management
- **Dio** for efficient and customizable HTTP requests
- **CLEAN Architecture** for maintainable, testable code
- **GetIt** for dependency injection
- **Pro Design & Pro Widgets** for responsiveness and UI consistency

---

## ✨ Features

- ✅ Display list of countries  
- ✅ View country details  
- ✅ Clean and scalable project structure  
- ✅ Follows solid principles for production-ready apps
